Sarvodaya — Library & Coaching Management System
Live: sarvodayalibrary.vercel.app
A full-stack web platform for managing a physical study library — live seat tracking, fee/payment status, shift management, and an AI assistant for admins — built entirely end-to-end using AI, from UI design and feature planning to development and deployment.

🎯 Project Goal
This project was built as an experiment in AI-augmented software development — using AI tools at every stage (design, planning, coding, deployment) to explore how much real productivity gain is possible when AI is treated as a full collaborator rather than just a code autocomplete tool.

✨ Features
Live Seat Tracking — Real-time view of vacant/occupied seats across the library (43 seats, 5 daily shifts)
AI Assistant (Admin Panel) — Conversational assistant that answers queries like vacant seats, unpaid students, shift demand, and stats, and can perform actions (with undo support)
Fee & Payment Status — Track which students have paid and who's pending
Admin Authentication — Secure login for library staff/admin
Contact & Enquiry Page — For prospective students to reach out
Responsive Design — Optimized for mobile and desktop
